# ระบบบันทึกการใช้งานเครื่องพ่นฆ่าเชื้อ · QSNCC

Web app (HTML ไฟล์เดียว) สำหรับ **บันทึกการใช้งานเครื่องพ่นฆ่าเชื้อ** และ
**จัดทำรายงาน** ของศูนย์การประชุมแห่งชาติสิริกิติ์ (QSNCC)

## วิธีใช้งาน
เปิดไฟล์ [`index.html`](./index.html) ด้วยเว็บเบราว์เซอร์ (Chrome / Edge / Firefox / Safari)
ได้ทันที — ไม่ต้องติดตั้งหรือเชื่อมต่อเซิร์ฟเวอร์ ใช้งานแบบออฟไลน์ได้

## ความสามารถ
- 📝 **บันทึกข้อมูล** การปฏิบัติงานแต่ละครั้ง พร้อมช่องกรอกอัตโนมัติ (autocomplete) จากข้อมูลเดิม
- 📋 **รายการทั้งหมด** — ค้นหา กรองตามเดือน/ผลตรวจ แก้ไข และลบข้อมูล
- 📊 **จัดทำรายงาน 4 ระดับ เลือกได้**
  - รายครั้ง (session)
  - รายเดือน (monthly)
  - รายไตรมาส (quarterly)
  - รายปี (yearly)
  
  แต่ละรายงานมีการ์ดสรุปตัวเลข กราฟแท่ง (แยกตามวัน/เดือน/โซน/เครื่อง) และตารางรายละเอียด
- 🖨️ **พิมพ์ / บันทึกเป็น PDF** ได้จากปุ่มในหน้ารายงาน
- 📄 **ส่งออก CSV** (เปิดใน Excel ได้ รองรับภาษาไทย UTF-8 BOM)
- ⬇️⬆️ **สำรอง / นำเข้า** ข้อมูลเป็นไฟล์ JSON

## การจัดเก็บข้อมูล
ข้อมูลถูกเก็บใน **localStorage ของเบราว์เซอร์** บนเครื่องที่ใช้งาน
- ข้อมูลไม่ถูกส่งออกไปที่ใด (เป็นส่วนตัว ปลอดภัย)
- แนะนำให้ **สำรองข้อมูล (JSON)** เป็นระยะ และก่อนล้าง cache เบราว์เซอร์
- หากต้องการใช้ร่วมกันหลายเครื่อง ให้ส่งออก/นำเข้าไฟล์ JSON

## โครงสร้างข้อมูล (ฟิลด์ที่บันทึก)
> ⚠️ **หมายเหตุ:** ไฟล์ Excel ต้นฉบับ `QSNCC_Disinfection_Machine_Registry.xlsx`
> ไม่ได้ถูกอัปโหลดเข้ามาในระบบ จึงยังไม่สามารถอ่านคอลัมน์จริงได้
> ฟิลด์ด้านล่างเป็นการออกแบบตามแนวคิดทั่วไปของทะเบียนเครื่องพ่นฆ่าเชื้อ
> **หากคอลัมน์จริงต่างจากนี้ แจ้งได้ จะปรับให้ตรงกับไฟล์ Excel**

| ฟิลด์ | คำอธิบาย |
|---|---|
| วันที่ / เวลา | วันเวลาที่ปฏิบัติงาน |
| อาคาร / โซน | พื้นที่หลักที่พ่น (จำเป็น) |
| จุด / ห้อง | ตำแหน่งย่อย |
| หมายเลขเครื่อง | รหัสเครื่องพ่น เช่น DM-01 (จำเป็น) |
| ผู้ปฏิบัติงาน | ผู้รับผิดชอบ (จำเป็น) |
| น้ำยาฆ่าเชื้อ | ชนิด/ความเข้มข้น |
| ปริมาณน้ำยา (มล.) | ปริมาณที่ใช้ |
| พื้นที่ที่พ่น (ตร.ม.) | ขนาดพื้นที่ |
| ระยะเวลา (นาที) | เวลาที่ใช้ปฏิบัติงาน |
| ผลการตรวจสอบ | ปกติ / พบปัญหา |
| หมายเหตุ | รายละเอียดเพิ่มเติม |

## การปรับแก้ฟิลด์
ฟิลด์ทั้งหมดกำหนดในไฟล์ `index.html`:
- ฟอร์มบันทึก: ส่วน `<form id="recordForm">`
- ตรรกะบันทึก: ฟังก์ชัน `saveRecord()`
- คอลัมน์ CSV: ค่าคงที่ `CSV_COLS`
